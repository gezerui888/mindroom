# Tracker

## Actions

Status is `open`, `in progress`, `blocked`, `done`, or `dropped`.
Mark an action `done` only when its source shows it complete.

## Risks

Impact and likelihood are `low`, `medium`, or `high`.
The trigger is the observable sign that the risk is turning into an issue.
