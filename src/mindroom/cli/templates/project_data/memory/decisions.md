# Decision Log

Add a row only for a decision someone with the authority to decide has made.
Drafts and proposals belong in `memory/questions.md` until they are decided.
Never rewrite an old row; when a decision is replaced, add the new one and mark the old one `superseded`.
Status is `active`, `superseded`, or `reversed`.
