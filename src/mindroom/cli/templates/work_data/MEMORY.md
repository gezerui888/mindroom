# MEMORY.md

Curated, durable memory for this person, which MindRoom loads on every turn.
Anything that changes week to week lives here or in the daily notes under `memory/`.

Conventions:

- Begin each entry with the date it was learned, as `YYYY-MM-DD`.
- Write an inference as `(inferred: source)` at the end of its entry.
- Place a conflicting entry directly below the older one and mark both `(conflict)` until settled.
- Promote a daily-note item only when it will matter again, and leave the raw detail in the note.
- Prune finished work and superseded facts, keeping a line under Corrections only when the old fact could resurface.
- The `memory` tool appends at the end of this file, so move new entries under the right heading when curating.
